# Angular Upgrade Skill

This skill provides targeted guidance for upgrading the Angular portfolio repository.

When this skill is loaded, focus on:

1. The current Angular stack: Angular `21.2.0`, Angular CLI `21.2.0`, and `@angular/material` compatibility.
2. Safe upgrade steps, using `ng update @angular/core @angular/cli` and `ng update @angular/material` when needed.
3. Dependency version mismatches in `package.json` and TypeScript compatibility requirements.
4. Minimal disruption to the current component layout, forms, and Material-based styling.
5. Verifying the Contact Me form, work history sections, and component templates after upgrades.

Provide a clear recommended workflow and identify likely deprecations or breaking changes for this repo.
